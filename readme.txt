This project investigates short-horizon cross-sectional return predictability
in large-cap US equities using daily OHLCV data.

Data:
- S&P 500 constituents (Wikipedia)
- Historical prices via Yahoo Finance

Methodology:
- Daily cross-sectional ranking by past k-day returns
- Long-short decile portfolio
- Daily rebalancing
- Transaction costs: 5 bps per turnover

Key Results:
- Annualized Sharpe: 1.1–1.4 depending on horizon
- Stable across subperiods
- Significant mean reversion at 3–5 day horizon

Limitations:
- Survivorship bias
- Yahoo Finance data quality
